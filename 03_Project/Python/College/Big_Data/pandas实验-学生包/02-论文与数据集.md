## 一、数据集：Online Retail（UCI，541,909 行）

### 1.1 正式引用（APA 格式）

> Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33

### 1.2 BibTeX

```bibtex

```

### 1.3 关键事实（备课可直接念）

| 项目 | 内容 |
|---|---|
| 数据提供方 | Daqing Chen，伦敦南岸大学（London South Bank University） |
| 业务主体 | 一家注册于英国的在线零售商店，主营礼品类商品，客户以批发商为主 |
| 时间范围 | 2010-12-01 ~ 2011-12-09（一年零九天） |
| 记录数 | **541,909 行** |
| 字段数 | 8 |
| 原始文件 | `Online Retail.xlsx`，22.6 MB |
| 下载地址 | https://archive.ics.uci.edu/dataset/352/online+retail |
| 许可 | UCI 机器学习库发布；课件中使用时请保留 DOI 与作者署名 |

> **课堂提示**：这份数据可以直接用于作业、论文和比赛，前提是**注明来源**。
> 这一点值得专门讲 1 分钟——很多学生以为"网上的数据都不能用"。

### 1.4 字段说明

| 字段 | 说明 |
|---|---|
| `InvoiceNo` | 发票号，6 位整数；以 `C` 开头表示该笔为取消（退货） |
| `StockCode` | 商品编码，5 位；`POST`（邮费）、`M`（手工调整）、`D`（折扣）、`BANK CHARGES`（银行手续费）等为特殊码 |
| `Description` | 商品名称 |
| `Quantity` | 数量；负数表示退货 |
| `InvoiceDate` | 开票日期时间（精确到分钟） |
| `UnitPrice` | 单价（英镑） |
| `Customer ID` | 客户编号（5 位）；缺失表示游客下单 |
| `Country` | 客户所在国家 |

### 1.5 与 Online Retail II 的关系（学生常问）

UCI 上还有一份 **Online Retail II**（2019 年发布，DOI `10.24432/C5CG6D`，CC BY 4.0）：
它把 2009-12-01 ~ 2011-12-09 的两年数据放进一张 Excel 的两个工作表，共 1,067,371 行。

其中工作表 `Year 2010-2011` 与本节这份 Online Retail **内容一致、行数一致（541,909 行）**。
本案例使用后者，因为文件只有 22.6 MB，课堂分发和读取都更快；引用时用 1.1 的 Online Retail 即可。

如果要做"跨年对比"的扩展作业，再下载 Online Retail II 的两个工作表：

> Chen, D. (2019). *Online Retail II* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5CG6D

### 1.6 数据集的"研究血统"

这份数据不是随手抓的，它来自一篇正式发表的客户细分研究：

> Chen, D., Sain, S. L., & Guo, K. (2012). Data mining for the online retail industry: A case study of RFM model-based customer segmentation using data mining. *Journal of Database Marketing & Customer Strategy Management*, 19(3), 197–208. https://doi.org/10.1057/dbm.2012.17

**这句话可以直接用在课堂上**：学生做的 T10（RFM 分层），正是这篇论文的核心方法；他们不是在抄作业，而是在复现一篇已发表研究的主线。

## 二、pandas 的原始论文（讲"为什么用 pandas"时引用）

### 2.1 pandas 的诞生

> McKinney, W. (2010). Data Structures for Statistical Computing in Python. In *Proceedings of the 9th Python in Science Conference (SciPy 2010)*, 56–61. https://doi.org/10.25080/Majora-92bf1922-00a

这是 pandas 作者 Wes McKinney 介绍 DataFrame 与 Series 设计动机的原始论文，篇幅只有 6 页，适合让学生课后读。

```bibtex
@inproceedings{mckinney2010data,
  author    = {McKinney, Wes},
  title     = {Data Structures for Statistical Computing in Python},
  booktitle = {Proceedings of the 9th Python in Science Conference},
  pages     = {56--61},
  year      = {2010},
  doi       = {10.25080/Majora-92bf1922-00a}
}
```

### 2.2 pandas 的定位

> McKinney, W. (2011). pandas: a Foundational Python Library for Data Analysis and Statistics. *Python for High Performance and Scientific Computing*, 1–9.

无 DOI，可在作者主页或 SciPy 会议论文集中找到。核心观点：数据分析需要**带标签的、可对齐的**数据结构，NumPy 的 ndarray 只解决了"同构数值数组"的问题。

### 2.3 底层依赖

> Harris, C. R., Millman, K. J., van der Walt, S. J., et al. (2020). Array programming with NumPy. *Nature*, 585, 357–362. https://doi.org/10.1038/s41586-020-2649-2

pandas 的列式存储建立在 NumPy 之上。讲 T12（向量化 vs `apply`）时引用这篇，说明"为什么向量化快"——底层是 C 循环 + 连续内存。

### 2.4 数据整理的方法论

> Wickham, H. (2014). Tidy Data. *Journal of Statistical Software*, 59(10), 1–23. https://doi.org/10.18637/jss.v059.i10

"整洁数据"三条原则：每列一个变量、每行一个观测、每张表一个观测单元。本案例的宽表 → 长表（cohort 矩阵）转换，可以直接引用这三条原则。

## 三、方法与业务论文（讲 T10 时引用）

### 3.1 RFM 的经典来源

> Hughes, A. M. (1994). *Strategic Database Marketing*. Probus Publishing.

RFM（Recency / Frequency / Monetary）方法最早在直邮营销中被系统化提出。书中提出"最近购买、购买频次、购买金额"三要素能有效预测客户响应率。

### 3.2 RFM 的学术检验

> Fader, P. S., Hardie, B. G. S., & Lee, K. L. (2005). RFM and CLV: Using Iso-Value Curves for Customer Base Analysis. *Journal of Marketing Research*, 42(4), 415–430. https://doi.org/10.1509/jmkr.2005.42.4.415

这篇论文做了一件重要的事：**检验 RFM 到底有没有用**。结论是 RFM 能区分客户价值，但简单加总不如基于概率模型的 CLV 精细。课堂上可以借此提醒学生：**RFM 是启发式方法，不是因果模型**。

### 3.3 本数据集的原配论文

见 1.6 节（Chen, Sain & Guo, 2012）。

## 四、可复现性与数据伦理（拓展阅读）

> Peng, R. D. (2011). Reproducible Research in Computational Science. *Science*, 334(6060), 1226–1227. https://doi.org/10.1126/science.1213847

讲"为什么 notebook 要能从头跑到尾"时引用。

> Wilkinson, M. D., et al. (2016). The FAIR Guiding Principles for scientific data management and stewardship. *Scientific Data*, 3, 160018. https://doi.org/10.1038/sdata.2016.18

FAIR 原则（可发现、可访问、可互操作、可复用）。讲数据管理规范时可用。

### 隐私说明（务必讲）

本数据集中的 `Customer ID` 已由数据提供方脱敏为编号，不含姓名、地址、支付信息。但课堂上仍应强调：

- 真实业务数据往往包含个人信息，分析前必须脱敏；
- 客户编号 + 消费记录的组合，在小样本中可能被"反推"出身份；
- 对外发布分析结果时，客户级明细不应公开。
