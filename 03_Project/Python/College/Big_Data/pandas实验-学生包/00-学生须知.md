## 一、这次实验做什么

一家英国在线礼品零售商把一年多的交易流水交给你，老板只问三句话：

1. **生意到底怎么样**——哪几个月在赚钱，哪几个月在掉？
2. **钱是哪些客户贡献的**——只能维护 20% 的客户，该选谁？
3. **货卖得怎么样**——哪些商品真赚钱，哪些只是卖得多？

你要用 pandas 从一份**没有清洗过的原始流水**出发，依次完成：体检 → 清洗 → 聚合 → 洞察 → 结论。
不是抄 API，是一次完整的数据分析项目。

## 七、常见坑（提前看，能省两小时）

1. `Customer ID` 读进来是 `float64`，因为有缺失——别直接 `astype(int)`，先 `dropna`。
2. 退货单 `Quantity < 0`，`Quantity * UnitPrice` 自然是负的；算退货金额要取正。
3. `InvoiceDate` 不 `parse_dates` 就做不了 `resample`。
4. `qcut` 遇到大量相同值会报 *Bin edges must be unique*，先 `rank(method='first')`。
5. `resample('W')` 的周锚点是**周日**，不是周一。
6. `apply(axis=1)` 能跑但很慢，能用向量化就用向量化。
