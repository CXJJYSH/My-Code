# 空元素

下面是一个图像元素的示例，它是一个空元素：

`<img>`
请注意，这个图像元素没有结束标签，也没有任何内容。 空元素不能有任何内容，只有一个开始标签。

有时你会看到使用 / 放在 > 之前的空元素，如下所示：

`<img />`
虽然许多代码格式化工具如 Prettier 会选择在空元素中包含 /，但 HTML 规格声明 / 的存在“并不表示开始标签是自闭合的，而是多余的且没有任何效果”。

在实际开发中，你会看到这两种形式，因此熟悉它们都很重要。
