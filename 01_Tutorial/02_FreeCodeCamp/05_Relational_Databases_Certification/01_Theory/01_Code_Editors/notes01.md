# Working with Code Editors and IDEs

## What is a code editor and IDE?

A code editor is any application that allows you to edit code files.

An IDE, or integrated development environment, is a full application that allows you to compile, run, and debug your code while you edit it.

A cloud-based editor is an online tool that allows users to write, edit, and manage code or text directly through a web browser without needing to install software locally.

## What Are Several Useful Keyboard Shortcuts for Maximizing Productivity in VS Code?

| Action                      | Windows                             | Linux                                 | macOS                                   |
| --------------------------- | ----------------------------------- | ------------------------------------- | --------------------------------------- |
| Save                        | Ctrl + S                            | Ctrl + S                              | Cmd + S                                 |
| Copy                        | Ctrl + C                            | Ctrl + C                              | Cmd + C                                 |
| Paste                       | Ctrl + V                            | Ctrl + V                              | Cmd + V                                 |
| Format file                 | Shift + Alt + F                     | Ctrl + Shift + I                      | Shift + Option + F                      |
| Search all files            | Ctrl + Shift + F                    | Ctrl + Shift + F                      | Cmd + Shift + F                         |
| Find and replace            | Ctrl + Shift + H                    | Ctrl + Shift + H                      | Cmd + Shift + H                         |
| Delete line                 | Ctrl + Shift + K                    | Ctrl + Shift + K                      | Cmd + Shift + K                         |
| Hide sidebar                | Ctrl + B                            | Ctrl + B                              | Cmd + B                                 |
| Increase editor zoom        | Ctrl + Plus                         | Ctrl + Plus                           | Cmd + Plus                              |
| Decrease editor zoom        | Ctrl + Minus                        | Ctrl + Minus                          | Cmd + Minus                             |
| Add cursor above/below line | Ctrl + Alt + Down / Ctrl + Alt + Up | Shift + Alt + Down / Shift + Alt + Up | Option + Cmd + Down / Option + Cmd + Up |
| Add cursor on click         | Alt + click                         | Alt + click                           | Option + click                          |
| Open command palette        | Ctrl + Shift + P                    | Ctrl + Shift + P                      | Cmd + Shift + P                         |
