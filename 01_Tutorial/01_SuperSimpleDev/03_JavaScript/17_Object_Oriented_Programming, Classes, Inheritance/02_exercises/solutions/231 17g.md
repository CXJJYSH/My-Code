**The point of this exercise is learn that private properties like #speed can not be accessed in a child class.**

In other languages, a property can be **public**, **private**, or **protected**(**protected** = it can be accessed inside a class <u>and</u> its child classes).

Object-Oriented Programming is less popular in JavaScript because it is missing some features of OOP, like protected properties.
