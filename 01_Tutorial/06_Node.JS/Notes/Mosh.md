# Node.js Tutorial for Beginners: Learn Node in 1 Hour

## 1. What is Node

Node.js is a open-source, cross-platform, runtime environment for executing JavaScript code outside a browser.

We often use Node to build back-end services, also called API, or Appilication Programming Interface.

Ideal for highly-scalable, data-intensive and real-time apps.
